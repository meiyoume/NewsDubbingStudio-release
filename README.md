# NewsDubbingStudio 安装包发布

新闻配音重构台（NewsDubbingStudio）的 Windows 安装包与更新包发布仓库。

## 下载

在右侧 [Releases](https://github.com/meiyoume/NewsDubbingStudio-release/releases) 页面
下载最新日期的 `NewsDubbingStudio-<日期>.zip`。

## 安装

解压后运行 `NewsDubbingStudio.exe`，详细步骤看压缩包里的《安装说明.txt》。

- 安装包不含模型；首次使用在 设置 → 识别与配音 → 模型下载 里一键下载。
- 以后的版本升级可以直接在软件内：设置 → 下载与维护 → 检查更新。
